# GrooveMorph Wiki

GrooveMorph is a beta-stage, phrase-aware rhythmic audio effect with four editable variations (A to D), seven rhythmic transformations, selectable musical and sample timing, presets, Euclid patterns, Print to WAV and an Easy mode. It is a rhythmic effect, not an instrument.

This wiki is a navigation layer. The [README](../../README.md), the [user help](../../help/README.md) and the specifications in [docs/specs](../specs/COMPLETENESS-MATRIX.md) are authoritative.

## Status

Beta. The portable core tests pass on Linux. The JUCE targets are built by CI. No DAW, audio-hardware or CLAP host test has been completed, so compatibility is not established. Open work is in [docs/TODO.md](../TODO.md).
