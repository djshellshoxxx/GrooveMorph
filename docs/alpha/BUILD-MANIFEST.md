# Build manifest

This repository copy is a template. The authoritative manifest (commit SHA, version, SHA-256, test and smoke results for the
exact binary) is generated by `.github/workflows/windows-alpha.yml` and shipped inside the ZIP as `BUILD-MANIFEST.md`.

- Product: GrooveMorph Windows x64 Standalone, version `0.1.0-alpha.<workflow run number>`
- Toolchain: windows-2022 runner, MSVC, CMake Release, JUCE 8.0.7 (FetchContent), C++20
- Contents: GrooveMorph.exe, README-ALPHA.txt, docs (feature status, known issues, user test guide, test results),
  ctest-windows.log, BUILD-MANIFEST.md, optional desktop screenshot; plus `<zip>.sha256`
- Not provided: installer, code signing, VST3 package in the ZIP, DAW validation
